### 1.2 本项目「唯一系统比喻词典」（基于真实代码逻辑 · 跨对话长期统一）

> **为什么必须定死唯一比喻词典？**
> 默认用户不懂代码和编程。如果今天对话拿“开餐馆”打比方、明天换一个 Agent 又拿“坐火车”打比方，用户每次都要重新脑内翻译，造成极大的认知负担。
> **铁律**：基于本产品真实的系统/代码逻辑，在这里定死**一套贴合实际运转机理的比喻体系**；此后**所有对话、所有 Agent 面向用户解释细节、汇报方案、写监理单时，一律沿用下表同一套比喻，严禁临时另换一套比喻，且面向用户完全去代码化、去字段化**。

- **全局总比喻**：`<例如：“总部档案库 + 按秒租用的个人云工位”，或“带自动对账锁的连锁门店与中央金库”。>`
- **核心部件唯一比喻映射表**：

| 真实系统逻辑 / 技术概念（仅限内部与 Agent 交接单用） | 面向用户的唯一固定比喻（以后每次对话必须用这个词） | 为什么贴合真实代码逻辑 |
| :--- | :--- | :--- |
| `<如：中心数据库 + 对象存储>` | `<总部档案金库>` | `<唯一真源、原件不可篡改、换设备不丢>` |
| `<如：前后端共享接口与事件表>` | `<全工地唯一水电规格表>` | `<两头必须按同一份尺寸施工，否则插头对不上>` |
| `<如：权限校验与配额熔断>` | `<门禁刷卡锁与水电总闸>` | `<确定性物理拦停，不靠口头嘱咐>` |
