# 两道楚河汉界详拆：3 句终极试金石与通用正反例对照库

> **为什么不能只喊“代码别越界”？**
> 实战一再证明：只看抽象口号，写代码的 AI 转头就会**换一层貌似高级的工程马甲**继续替大脑做决定。本指南把**两道分界线**、**3 句一刀切透的试金石**与 **9 组真实工程沉淀的通用正反例**焊在一起，设计阶段与审码阶段均可直接对照。

---

## 一、第一道线：官方底座 / 脚手架 vs 自研薄层

打个比方：**租了一栋水电煤消防全齐的精装修写字楼，你的任务是按公司业务摆工位和建档案室，而不是把大楼的主水管砸开自己重埋一套土水管。**

1. **能复用就 0 行自研**：会话管理、重试退避、上下文压缩、文件存储、定时调度、认证基础设施、官方 UI 组件等成熟底座已有的能力，原装直用。
2. **原则上绝不魔改底座**：不 Fork、不打 `pnpm patch`、不偷读私有内部字段；若自有插件与底座冲突，第一反应检查自家适配层，绝不改底座源码。
3. **只通过官方插座接入**：每个自研模块写清接入哪个标准扩展点，并在卸载/失败时完整清理监听器、定时器与租约。
4. **确需替换原装模块时**：动笔前必须通读被替换模块的全部源码（包括事件总线监听、隐式副作用与清理逻辑），严禁只扫一眼接口文档就动手。

## 二、第二道线：代码层 vs 提示词层（3 句终极试金石）+ 快模型按需推荐

打个比方：**开公司请了一位聪明总经理（大模型大脑），再配一间诚实可靠的工具房与财务锁（代码层）。** 拿不准某条规则该归谁时，3 秒过完这三句试金石：

1. **试金石 1 · 是不是确定性物理事实、安全铁锁、计时器、精确算账或纯格式门卫？** → **归代码层**。
   - 多租户/跨用户物理隔离、不可篡改底稿、资金冻结与精确结算、步数/频率硬熔断、明确倒计时器、精确文本 Diff、**纯可执行性校验**（只查必填是否为空、引用的对象 ID 在系统里真不真实存在，绝不审语义好坏）、真实完整报错原样透传、零干扰异常探针。
2. **试金石 2 · 需不需要听懂人话、看懂现场上下文、权衡利弊、判断重要度或决定下一步怎么走？** → **归提示词层 + 大模型自主调用工具**。
   - 识别自然语言意图、判断网页是否撞上登录墙、判断大文档先翻哪几章、判断文档敏感度与脱敏建议、判断外部改动是修错别字还是改核心条款、判断遇错该换路还是求助真人。
3. **试金石 3 · 有没有换件马甲偷塞“如果……就……”？（专抓隐形越界！）**
   - 拆了关键词词表 → 又偷加“必须先执行完 A/B/C 三步才准求助”的死流程锁？**违宪！**
   - 拆了 600 字硬截断 → 又改成“代码定个字数阈值，超长就程序自动改写摘要”？**违宪！**
   - 拆了后台自动弹系统授权窗 → 又叠“三层拦截 + 5 秒冷却 + 遇错直接掐死循环”？**违宪！**
   - 拆了写死打分权重 → 又让代码按引用次数自动把结论升格为高可信？**违宪！**
   - **只要代码在替大脑做业务/语义/策略判断，无论披着多优雅的工程马甲，一律否决！**

> **快模型不是必选项——何时才推荐用户采用快模型衔接方案？**
> 绝大多数常规任务只需要“代码层 + 主力大模型提示词层”，完全不必为了赶时髦强行加一层快模型。
> **只有遇到确实适合的灰区衔接场景**——即需要高频、低成本地把“外部模糊非结构化信号”转成“代码可执行判断”（典型例：外部群聊旁听判断这句话是不是在叫系统、旁路零干扰结果交付探针只判 `YES/NO`）——才主动向用户**推荐**采用快模型方案。且无论何时都必须守住底线：**绝不拦在系统内 1 对 1 主链路门口，绝不拿弱模型替代主力大脑来降智省钱。**

## 二点五、Agent 与代码结构化交接的 5 步铁律（解决“非确定大脑 ↔ 确定性代码”必炸难题）

只要系统里存在**大模型向代码提交结构化数据**的环节（如创建任务卡、提交审批单、落盘摘要、调关键业务工具），必须严格落成完整 5 步闭环，缺一不可：

1. **第一棒给齐“清晰表头 + 完整真实填表示例”**：不仅给字段名和类型，还要给一张真实填好的样板单；**凡枚举/档位类选择题，必须同时写明默认倾向、判定标准与防误判边界**（杜绝模型出于保守本能宁可错杀）。
2. **程序只检“可执行性”两条红线，严禁审语义**：
   - 只检：① 必填字段是否为空（或类型/枚举无法执行）；② 需要明确选对象（人/群/文件/单据）时，选中的对象是否在系统中真实存在；
   - **严禁**程序去审查措辞好不好、总结全不全面、有没有用某个词等模糊语义；
   - **严禁**后台偷偷补假默认值（往往会盖丢真实数据并掩盖上游缺口）；
   - **严禁**代码静默抹平自相矛盾或自动勾选未完步骤并宣告业务结束。
3. **检验不通过，带着明确错误原因打回大模型重填，再给 2 次机会**：告诉模型“具体哪一格错、为什么无法执行”，由模型自己修正重交。
4. **连续 3 次未填对，才正式触发程序报错**：防止无限打回死循环暗烧算力。
5. **正式程序报错也绝不直接拍到用户脸上，必须交还给 Agent 处理**：把程序级真实报错原样回传给 Agent，由 Agent 决定换一种办法继续办，或用人话向用户交代清楚前因后果，而不是弹出冷冰冰的红色技术报错让用户干瞪眼。

## 二点六、活态错题本怎么积累、怎么淘汰？（绝不攒成废纸堆）

错题本不是“已修 Bug 记事本”——如果把所有修过的具体字段拼写错误都堆进去，几个月后错题本几万字，不仅拖慢每次思考、还全是对未来毫无用处的废上下文。正确运营法只有 **4 条**：

1. **什么时候才往错题本里记？** 仅当一次审查、视觉实测或线上故障中，① 追出了**全仓缺失的底层编写原则**并完成了第 0 层 → 第 2 层思维跃迁；或 ② 发现某种**换皮越权坏习惯跨越两个以上模块反复复发**时，才提炼入本。
2. **只记什么、坚决不记什么？** 只记「**思维跃迁示范**（表面症状 → 原地踏步错法 → 追出的缺失原则 → 升维硬机制 → 一句生活比方）」和「**顽固换皮马甲镜子**」；坚决不记“某天某接口漏了判空”这类一次性老 Bug。
3. **必须随 PR 合入 GitHub `main` 正本**：错题结论严禁只停留在某次聊天记录里，必须和整改代码同船合入 GitHub `main`，确保未来每一个进场干活的 Agent 开工就自动获得免疫。
4. **定期做减法卸载**：当某条错题对应的风险已经被编译器共享类型、机械门禁脚本或新一代更强模型永久消除时，果断从错题本里删掉旧条目，让常驻上下文越变越轻、越变越锋利。

## 三、9 组通用正反例对照库

| 序号 | 典型场景 | ❌ 反例（常见错法 + 换皮马甲） | ✅ 正例（清晰的脑手楚河汉界） |
| :-: | :--- | :--- | :--- |
| **1** | **网页自动化与人工求助卡** | 在浏览器工具里塞业务猜词表（如“扫码登录”“验证码”），见字自动弹求助卡并给模型下封口令；换皮后改成“必须先查完所有标签页才准求助”或单造一个“切标签页”特例按钮。 | **代码层**：只提供纯净完整的通用浏览器工具 + 物理断线的独立求助卡工具，0 条业务/页面状态 `if -> then`。<br>**提示词层**：留一句常识——遇登录墙不猜密码，看清现场后自主决定是否求助。 |
| **2** | **自然语言意图识别与定时任务** | 在用户的话送进大模型前，代码先扫词截胡——一碰见“每天”“每周”就强行代建定时提醒（把“帮我写一篇面向**每天**整理纪要的行政看的文章”误建成闹钟）。 | **代码层**：除用户亲手点击的界面显式按钮或明确斜杠命令外，所有自然语言原封不动直达大模型。<br>**提示词层**：大模型读懂完整语境后，自主决定要不要调定时工具。 |
| **3** | **多模态读取与防参数幻觉** | 模型编造 60 位长编号调付费接口，代码在门口写正则事后猜假词；换皮后过度设计“不管图片还是常规文件，凡事必须先经过程序黑盒转译中间层才能递给模型”。 | **代码层**：图、文、常规文件直接交给具备对应原生能力的模型读（当前模型读不了就换支持该能力的模型）；仅对物理绕不开的精确算账、二进制生成、敏感凭证或机器句柄的确定性注入用工具。<br>**提示词层**：冷门确实读不了的文件坦诚直说“读不了”。 |
| **4** | **大文档阅读与防上下文撑爆** | 代码拍脑袋写死“超 600 字从头硬剪丢弃”；换皮后改成“代码定个阈值，判断是大块内容就由程序自动落盘改写摘要”。 | **代码层**：拆光静默硬截断和拍脑袋大小阈值，提供看目录 + 按章节/页码按需读取的工具；工具桌保持精简。<br>**提示词层**：引导大模型遇大部头先忠实记录目录和结构要点，需要哪块再按需翻阅。 |
| **5** | **权限弹窗、审批与遇错处理** | 把会触发系统授权弹窗的调用塞进每秒 2 次的后台循环，无权限时 1 分钟炸出 100 个弹窗；换皮后叠三层冷却并顺手写死“循环遇报错直接停掉”。 | **代码层**：把“弹权限/发审批”剥离为独立显式工具，后台循环绝不暗藏打扰弹窗；遇报错既不无脑撞墙也不擅自替大脑掐死流程，把真实完整报错原样交还大模型。<br>**提示词层**：大模型读懂报错后自己决定请人开闸还是换路走。 |
| **6** | **隐私安检、格式校验与可信度评估** | 代码用正则扫“薪资/银行卡”强判高敏，或按引用次数自动套公式打“可信度 0.92”；或者走向另一极端——完全不做结构化校验任由缺字段崩掉下游。 | **代码层**：提供安检隔间与明确超时机制、按模型标出的片段生成真实物理脱敏副本、**纯可执行性格式门卫**（只查必填不空与引用对象真实存在，不合格打回重试，绝不审语义），以及独立显式的评级工具。<br>**提示词层**：大模型读懂语义给出敏感档位、脱敏建议与可信度判断。 |
| **7** | **外部活链接/文档变更巡查** | 定时无脑把 50 页全文喂给模型重读烧钱；或拉到“401 请先登录”空壳页直接覆盖旧快照；或代码写死“改动少于 10 个字自动忽略”。 | **代码层**：0 成本纯代码指纹比对 + 精确红删绿增 Diff；遇 401/404/空壳页硬防伪绝不覆盖旧版，原样报错通知拥有者；有真实变动只如实递变动单，绝不替大脑判重不重要。<br>**提示词层**：大模型看变动单自行判断是改错字还是改核心条款。 |
| **8** | **多租户/多用户平等与端侧缺口** | 源码里为测试账号或大客户写 `if (tenant === 'vip')` 特判；端侧缺依赖时提议“工程师连上客户电脑手动装环境凑合过关”。 | **代码层**：数据库层全客户平等强隔离，0 单客户特判；端侧缺口一律靠官方安装包、轻探针引导或服务端升级全员通用根治。<br>**提示词层**：提示词、技能与示例 100% 脱敏，不写任何单行业/单客户测试词进全员通用底座。 |
| **9** | **经营统计与人类阅读口径** | 让 AI 翻几百条聊天流水自己心算汇总数据；或后端把防浮点误差的底层微整数（如 `1000000` 代表 `1 元`）直接混在返回里递给大模型读，干扰模型算账。 | **代码层**：确定性统计一律代码直算供数，递给大模型和前端的账目一律转换为**带明确单位的人类可读口径**。<br>**提示词层**：大模型专注解读数据背后的业务含义与改进建议。 |
