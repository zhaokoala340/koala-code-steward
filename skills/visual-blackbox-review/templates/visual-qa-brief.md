### 四、结构化战报输出格式（严格按此交付）
1. **验收标准逐条判定表**：按编号逐条列出「当……时 / 应该…… / 实际看到 / `PASS·FAIL·BLOCKED` / 证据」，任何一条未亲眼看到即不得判 `PASS`。
2. **场景总览战报表**：逐场景给出 `PASS / FAIL / PARTIAL / BLOCKED`、实测耗时与亲眼看到的屏幕证据摘录。
3. **分级缺陷清单（P0 / P1 / P2）**：每条缺陷必须包含「精确复现步骤 + 实际屏幕现象 + 期望结果 + Console 报错 / HTTP 状态码 / 截图路径」。
   - `P0`：白屏、宕机、资损、数据丢失/串库、越权泄密、未完成却显示已完成；
   - `P1`：核心主链路失效、前后端字段错位、并发串话、未捕获 5xx、明显错误引导；
   - `P2`：文案瑕疵、轻微样式错位、非阻塞体验优化。
4. **最终裁决**：明确给出 `READY_FOR_PROD` 或 `NEEDS_FIX_AND_RETEST`，并附 3 句真实付费用户的直白体感总评。
